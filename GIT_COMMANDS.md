
# Essential Git Commands

## Introduction
Git is a version control system that allows developers
to track changes to files and manage project history.

## 1. git init
Initializes a new Git repository.

```bash
git init
```

## 2. git status
Displays the current status of the working directory.

```bash
git status
```

## 3. git add
Stages files before committing changes.

```bash
git add README.md
```

## 4. git commit
Records staged changes in the repository history.

```bash
git commit -m "Add project documentation"
```

## 5. git push
Uploads local commits to a remote repository.

```bash
git push origin main
```

## 6. git pull
Downloads and integrates changes from a remote repository.

```bash
git pull origin main
```

## Conclusion
These Git commands provide the foundation for managing
project changes and working with GitHub.

## 7. git log

Displays the history of commits in a repository.

```bash
git log --oneline
```
